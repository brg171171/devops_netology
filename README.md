# Какие файлы игнорируются

Правила `.gitignore` действуют в каталоге, где он находится, и во вложенных каталогах. Символ `*` означает любую последовательность символов в имени. Завершающий `/` указывает, что правило относится к каталогу; его содержимое тоже игнорируется.

| Правило | Что будет игнорироваться |
|---|---|
| `.terraform/` | Любой каталог с именем `.terraform` и всё его содержимое. |
| `*.tfstate` | Имена, оканчивающиеся на `.tfstate`, например `terraform.tfstate`. |
| `*.tfstate.*` | Имена, содержащие `.tfstate.` с любыми символами до и после этого фрагмента, например `terraform.tfstate.backup`. |
| `crash.log` | Имя, точно равное `crash.log`. |
| `crash.*.log` | Имена, начинающиеся с `crash.` и оканчивающиеся на `.log`, например `crash.123.log`. |
| `*.tfvars` | Имена, оканчивающиеся на `.tfvars`. |
| `*.tfvars.json` | Имена, оканчивающиеся на `.tfvars.json`. |
| `override.tf` и `override.tf.json` | Имена, точно равные `override.tf` или `override.tf.json`. |
| `*_override.tf` и `*_override.tf.json` | Имена, оканчивающиеся на `_override.tf` или `_override.tf.json`, например `local_override.tf`. |
| `.terraform.tfstate.lock.info` | Имя, точно равное `.terraform.tfstate.lock.info`. |
| `.terraformrc` и `terraform.rc` | Имена, точно равные `.terraformrc` или `terraform.rc`. |

Поскольку в этих действующих правилах нет начального `/`, совпадения находятся не только рядом с `.gitignore`, но и во вложенных каталогах. Кроме правила `.terraform/`, шаблоны не ограничены только обычными файлами: если с шаблоном совпадёт имя каталога, Git проигнорирует и его содержимое.
